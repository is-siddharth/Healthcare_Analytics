# 🏥 Healthcare Data Analytics

An end-to-end data analytics project that explores hospital data to understand patient admissions, hospital operations, treatments, and financial performance.

The project uses **SQL Server, Power BI, Excel, and Python** to turn raw data into meaningful insights.

## 🎯 Project Objectives

- Organize hospital data into a relational database.
- Analyze patient admissions, treatments, and hospital activity.
- Explore revenue, billing, and insurance coverage.
- Build interactive dashboards for easier analysis.
- Use Python to inspect data, identify patterns, and discover further insights.

## 🛠️ Tools Used

- **SQL Server:** Created and managed the hospital database, tables, and relationships.
- **Power BI:** Built an interactive dashboard to explore hospital performance.
- **Excel:** Used Power Pivot to connect tables and created a dashboard with PivotTables, slicers, and KPIs.
- **Python:** Performed data cleaning, data quality checks, exploratory analysis, and visualizations using Pandas, NumPy, Matplotlib, and Seaborn.

## 🔄 Project Workflow

1. **Database Creation:** Designed a relational database containing patient, admission, doctor, treatment, medicine, billing, insurance, and other hospital-related data.
2. **SQL Analysis:** Structured the data and used SQL queries to retrieve and analyze information.
3. **Power BI Dashboard:** Connected SQL Server to Power BI and built an interactive dashboard.
4. **Excel Dashboard:** Imported the data into Excel, created relationships using Power Pivot, and developed a dashboard with interactive filters.
5. **Python Analysis:** Connected Python to SQL Server for further inspection, cleaning, statistical analysis, and visualization.

## 📊 Key Areas of Analysis

- Patient demographics and admissions
- Department-wise hospital activity
- Admission types and trends
- Length of hospital stay
- Treatment activity
- Revenue and billing patterns
- Insurance coverage
- Relationships between hospital activity and financial outcomes

## 💡 Key Takeaway

This project demonstrates how different tools can work together to solve different parts of a data analytics problem — from storing and querying data to exploring patterns and presenting insights through dashboards.

**The goal is not just to analyze data, but to make it easier to understand and use for better decisions.**
